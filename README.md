# 麦门轻食策 · mcd-light-diet

> 科学减重，麦门也能吃。
> 输入你的身体数据和减重目标，自动生成七日三餐方案——既能在麦当劳点单（含领券+下单入口），也能切换成家常减肥食谱。

## 它解决什么问题

减肥期最大的痛点不是「不知道怎么吃」，而是：

- 不知道自己每天该吃多少卡、该吃多少蛋白；
- 想吃麦当劳又怕一不留神超标，只能硬扛着不吃；
- 网上的减脂食谱要么难做、要么不好坚持。

麦门轻食策，把你的身体数据变成**一份可执行的三餐方案**，而且给你两条路选：

1. **麦当劳套餐**——减肥也能吃麦门，热量/蛋白都在预算内，还能一键领券、直接下单；
2. **普通减肥食谱**——家常低卡高蛋白，附食材和做法，想自己做饭时切换过去。

## 核心特性

- **个人化热量计算**：BMR / TDEE / 热量缺口 / 三大营养素，一次算清。
- **一日三餐方案**：按 30% / 40% / 30% 分配，每餐都卡在预算内。
- **两类套餐切换对比**：麦当劳套餐 ↔ 普通食谱，并排看热量、蛋白质、价格。
- **一键领券 + 直接下单**：麦当劳套餐直接接麦当劳 MCP 领券和下单。
- **真实数据**：麦当劳的价格、营养、券信息全部来自 MCP 实时接口。

**输入**：女，28 岁，165cm，65kg，目标 30 天减 5 斤，轻度活动

**输出**：BMR 1380 千卡 · 每日目标摄入 1256 千卡 · 蛋白质 104g

## 工作原理

### 1. 热量目标计算（`diet_planner.py`）

- **BMR**（Mifflin-St Jeor）：`10×体重 + 6.25×身高 − 5×年龄 + (男5/女−161)`
- **TDEE** = BMR × 活动系数
- **每日缺口** = 目标斤数 ÷ 2 × 7700 ÷ 天数
- **每日目标摄入** = TDEE − 每日缺口（低于安全下限自动提示）
- **营养素**：蛋白 1.6g/kg、脂肪 25%、碳水补足

### 2. 套餐生成（`optimizer.py`）

- 麦当劳套餐：在每餐热量/蛋白预算内，用「组合枚举 + 剪枝」求最优组合；
- 普通食谱：从内置家常食谱库匹配最接近预算的菜式。

## 快速开始

### 方式一：作为 WorkBuddy Skill 使用（推荐）

1. 申请麦当劳 MCP Token（见 [mcd-mcp-server](https://github.com/M-China/mcd-mcp-server)）；
2. 把本仓库的 `SKILL.md` 作为 Skill 导入 WorkBuddy；
3. 配置 MCP 连接（参考 `mcp-config.example.json`，把 `${MCD_MCP_TOKEN}` 换成你的 Token）；
4. 直接说：「我 28 岁，165，65kg，想 30 天减 5 斤，帮我出一份一日三餐方案」。

### 方式二：独立运行脚本

```bash
# 减重方案生成（端到端演示）
python3 diet_planner.py

# 双约束点单优化
python3 optimizer.py
```
